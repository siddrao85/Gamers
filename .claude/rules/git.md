# Git workflow
- Branch names: `feat/<short-name>`, `fix/<short-name>`, `chore/<short-name>`.
- Never force-push shared branches; never rewrite history someone else has pulled.
- Commit messages: `type(scope): summary` in the imperative, under 72 chars; body explains why.
- Open PRs small and focused; describe what changed, why, and how it was verified.
